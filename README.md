# Student Result Finder System (Python)

## 📌 Project Description
The Student Result Finder System is a Python-based project that demonstrates the use of **Binary Search** and **Object-Oriented Programming (OOP)** to efficiently store and retrieve student academic records.

The system maintains student data in sorted order by roll number and uses binary search to achieve fast lookup with time complexity **O(log n)**.

---

## 🛠️ Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Binary Search Algorithm
- Command Line Interface (CLI)

---

## ⚙️ Features
- Add student records
- Display all student records
- Search student results using Binary Search
- Automatic grade calculation
- Efficient searching for large datasets
